WHAT IT READS

Network

Every fetch and XHR: status, timing, headers, request and response bodies. Copy any call as a cURL command.

Console

Logs, warnings, uncaught exceptions and unhandled promise rejections, captured from page load.

Storage

LocalStorage, SessionStorage and cookies for the current page. Long-press any value to copy it.

KNOWN LIMITS

Images, CSS, fontsnot captured — they never pass through fetch or XHR
The document requesthappens before the agent exists
HttpOnly cookiesinvisible to any injected script, by design
Cross-origin iframesblocked by same-origin policy — not fixable
